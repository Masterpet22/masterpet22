## Tecnologías

- **Frontend:** JavaScript, TypeScript, React, Next.js, HTML, CSS, Canvas, WebGL y PWA.
- **Backend:** Node.js, Express, NestJS, Supabase y Firebase.
- **Datos:** PostgreSQL, MySQL, Redis y SQLite.
- **Calidad:** Playwright, Vitest, ESLint, pruebas unitarias, accesibilidad y GitHub Actions.
- **Mobile:** React Native, Expo, Capacitor y Android.

## Cómo trabajo

- Empiezo por el problema del usuario y convierto la idea en un flujo comprobable.
- Separo la lógica de negocio de la interfaz para facilitar pruebas y evolución.
- Documento decisiones, límites y estado real del producto.
- Priorizo privacidad, accesibilidad, rendimiento y funcionamiento sin conexión cuando aportan valor.

## En qué estoy trabajando

- **Kinetra:** convertir el editor 2D en un producto sólido para creadores y desarrolladores de juegos.
- **CompClick:** validar una herramienta profesional para reconciliar datos sin subir información sensible.
